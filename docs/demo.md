# The demo site

[Open the live demo]({{ site.demo_url }}){: .btn .btn-primary }

The demo lets you click through the real web dashboard without installing
anything and without seeing anyone's real figures.

## What it is

A **static snapshot of the real dashboard**, built from **made-up data**:

- about **twenty fictional games**, each with a month-to-date turnover between
  **$500k and $2.5M**;
- generated by a **seeded model**, so the made-up studio can be rebuilt the
  same way;
- **replayed through the real collector**, so the trails and every figure
  derived from them come from the same code that runs against a real studio;
- then **crawled into static pages** and hosted on **S3**.

No studio, game, player or figure in it is real.

## What to expect

Because the pages are a snapshot, they do not change while you watch: the
figures are those of the moment the demo was built. Anything that posts back
to a server, such as turning on sign-in, changing Settings or dismissing a
warning, has no server to post to.

## Building and deploying it

Two npm scripts make the demo:

```bash
npm run demo:build
```

builds the snapshot: it generates the made-up studio from the seeded model,
replays it through the collector, and crawls the dashboard into static pages.

```bash
npm run demo:deploy -- --bucket acme-demo-site
```

uploads the built pages to the S3 bucket you name, for static hosting.
